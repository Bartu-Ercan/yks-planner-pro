# YKS Planner Pro Design Brief

## Product

YKS Planner Pro is a Turkish study planning web app for students preparing for the YKS exam.

It is not a landing page. It is a focused productivity dashboard.

## Main Goal

Refine the current app design direction into a more polished, commercial, reusable design system.

Keep the existing dark planner feeling, colorful subject accents, compact weekly layout, and theme-based visual personality.

## Reference Direction

Use the current app screenshots as the main visual reference.

Keep:

- Dark dashboard base.
- Colorful theme accents.
- Subject-based task colors.
- Compact 7-day planner structure.
- Study-focused mood.
- Productive, serious, premium feeling.

Improve:

- Spacing consistency.
- Visual hierarchy.
- Mobile layout.
- Task cards.
- Planner columns.
- Modals.
- Buttons and controls.
- Empty states.
- Progress summary.
- Theme selector.

Avoid:

- Generic SaaS dashboard style.
- Marketing landing page.
- Oversized hero sections.
- Childish exam app visuals.
- Purple gradient-heavy style.
- Decorative blobs or abstract backgrounds.
- Low-density card-heavy layout.

## Audience

Turkish high school students preparing for YKS.

The UI should feel focused, motivating, modern, and reliable.

## Core Screen

Design the main planner dashboard.

Required elements:

- 7-day moving planner view.
- Left and right day navigation.
- Current visible date range.
- Subject-based task cards.
- Add task action.
- Bulk add task action.
- Completion state.
- Study duration display.
- Weekly progress summary.
- Account/login state.
- Theme selector.
- Mobile responsive version.

## Core Interactions

- Add a task to a visible day.
- Mark task as completed.
- Enter study duration after completion.
- Drag a task between days.
- Move the visible 7-day window one day left or right.
- Switch visual theme.
- Use as guest or signed-in user.

## Visual Tone

Focused.
Premium.
Calm.
Energetic through accents, not through clutter.
Dense but readable.
Modern but not generic.

## Final Constraint

Do not replace the current design identity. Upgrade it.
